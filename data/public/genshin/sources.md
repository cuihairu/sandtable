# 公开基准数据来源（Genshin Impact 抽卡）

采集日期：2026-10-31。所有数值均可溯源，禁编造。抓取失败的样本如实标注缺失。

## 1. 社区全量统计样本（主校准基准）

- **数据集**：`MsExcel85/genshin-drop-rate`，玩家提交愿望数据驱动的 5★/4★ 掉率研究，
  发表于 HoYolab 2025-06-10（post_id=39248513）。
  - 仓库：https://github.com/MsExcel85/genshin-drop-rate
  - 论文（HoYolab）：https://www.hoyolab.com/newArticle/1?post_id=39248513
  - 数据集文件：`dataset.json`（152 个 banner 记录，每个含 `5star_pity1..90` / `4star_pity1..10` 计数）
  - 抓取：`curl https://raw.githubusercontent.com/MsExcel85/genshin-drop-rate/main/dataset.json`
- **本仓聚合**（`character-event-pity.json`，仅 character_event 型 banner）：
  - banner 数：74
  - 5★ 命中总数：22,047,495
  - 均值抽数：60.095
  - 综合概率（1/均值）：1.664%
  - 逐抽经验条件率：抽 1 约 0.686%；抽 1–73 均值约 0.708%；**抽 74 起跳至 6.7%，此后每抽约 +6%**；
    抽 90 为 100%（硬保底）
  - 注：上述「抽 90 为 100%（硬保底）」由数据构造恒等——本仓聚合只含 90 个抽位，反向累计
    首步 surv = count[90]，故 rate[90] = count[90]/count[90] = 1.0 与数据无关，非独立硬保底
    证据（同口径见 `crates/sandtable-core/tests/public_calibration.rs` 的恒真性注记）。真实可核的
    是 90 抽边界样本量 count[90]（实测 485 > 0）与抽 89 经验率（约 52%，显著低于 100%）；「90 抽
    硬保底」的独立依据以官方公示规则为准（见 §2）。
  - 注：抽 86–89 经验率出现非单调回落（69.4%→61.3%→49.1%→52.1%），对真实单调软保底曲线不可
    能，判为数据集高抽段伪影（玩家提交数据在 90 抽硬保底附近的选择/截断偏差），不作模型偏差依据。
  - 注：抽 1–73 经验率均值 0.708% 高于官方 0.6%，系玩家提交数据早期命中被过报的已知偏差
    （选择/保证机制混杂），故社区均值 60.095 低于官方 1/0.016=62.5；模型校准以**官方公示率
    与软保底曲线形态**为准，社区样本均值仅作参考并如实说明偏差。

## 1b. 本仓聚合（其余三个池型，2026-11-01 增补）

同源数据集 `dataset.json`（见 §1）按 banner_type 拆分的其余聚合，格式与 character-event 一致。
关键数字（`per_pity_counts` 反向累计得逐抽经验条件率；「软保底起点」= 经验率首次跳到
基准段 2 倍以上的抽位；「硬边界」= 计数最后非零抽位）：

- **weapon_event**（`weapon_event-pity.json`）：75 个 banner，5★ 命中 6,252,311，
  均值 49.8111，综合 2.008%（社区口径）。基准段（抽 1–45）均值 0.911%；
  **软保底 63 起**（抽 62→63 经验率 1.46%→8.29%，此后每抽约 +6.9%）；
  **硬边界 80**（81–90 抽位计数为 0，与官方 80 抽硬保底一致）。
- **standard**（`standard-pity.json`）：dataset 中仅 1 条记录（banner_id 200001，全时期常驻
  祈愿合并），5★ 命中 5,719,299，均值 49.1651，综合 2.034%（社区口径）。
  **软保底 74 起**（抽 73→74 经验率 1.55%→7.46%，此后每抽约 +5.9%），硬边界 90。
- **chronicled_wish**（`chronicled_wish-pity.json`）：2 个 banner（集录祈愿，仅开放过两期），
  5★ 命中 162,413，均值 54.4918，综合 1.835%（社区口径，样本量最小）。
  软保底 74 起（+6.1%/抽），硬边界 90。

数据质量如实记录：

- **绝对水平普遍过报**：三池社区综合率（2.008%/2.034%/1.835%）均高于对应官方公示值
  （武器 1.85%、常驻 1.6%、集录≈角色同结构 1.6%）。原因同 §1 注记——玩家提交数据的
  早期命中过报；其中 **standard 记录最重**：抽 1 经验率 1.156%（≈官方基础率 0.6% 的
  1.9 倍），单条合并记录的选择偏差比按期拆分的 event 池更重。
- **结构结论可信**：过报不改变软/硬保底的**位置**——武器 63/80、常驻 74/90、集录 74/90
  与官方公示及社区多源一致，故校准用「官方率 + 社区位置」，社区绝对水平仅作参考。
- **standard 反驳「常驻无软保底」预设**：任务预设常驻池无软保底，但 standard 记录
  74 抽起经验率明确爬坡（1.55%→7.46%→13.28%…），且官方公示常驻与角色同结构
  （0.6%/1.6%/74 软/90 硬）。**常驻池有软保底，与角色池同构**，本仓按此校准。

## 2. 官方公示概率（校准基准）

- 数值（Genshin Impact 祈愿规则，5★ 角色）：基础概率 **0.600%**，综合概率（含保底）**1.600%**，
  **90 抽以内必出**；软保底自 **74 抽**起每抽约 +6%。
- 溯源：官方 HoYoverse 祈愿规则公告为规范来源；本会话直连官方站点/HoYolab 公告页均为
  客户端渲染或 403（反爬），未能逐字抓取公告正文。上条第 1 项 HoYolab 论文的
  README/notebook 明示官方模型 `five_star_official_rates = [0.6]*89 + [100.0]`（notebook
  自注 "Official drop rates (uniform probability distribution)"），即 0.6% × 89 抽 + 90 抽
  硬保底 100% 的**平坦率模型（无软保底）**。该平坦模型综合概率 = 1/69.70 ≈ 1.435%
  （期望 69.70 抽），并非官方公示综合概率 1.600%（期望 62.5 抽）；官方 1.6% 仅在含软保底
  爬坡（74 抽起每抽约 +6%）时成立，被引平坦模型不含软保底，不能支撑所引 1.6% 数值。
  **故本仓模型校准以官方公示率（0.6% 基础 / 1.6% 综合 / 74 起软保底 +6% / 90 硬保底）为准**，
  该 notebook 平坦模型仅作社区研究参考，不作「官方数值已用真实数据验证」的依据。如需官方
  公告原文，需人工开浏览器核对（如实标注，不脑补）。
- 数值（Genshin Impact 武器祈愿，2026-11-01 增补）：基础概率 **0.700%**，综合概率 **1.850%**，
  **80 抽以内必出**；软保底自约 **63 抽**起（社区多源 62–63）；双 UP 武器各 37.5%，单次出
  指定 UP 概率 37.5%/次、未歪保底后 75%/次（即**无 50/50**，首次出 UP 概率 75%）；「定轨」
  （Epitomized Path）最多 2 点，第 2 点后必出所定武器（最坏 160 抽）。
- 武器数值溯源：官方 HoYoverse 祈愿规则为规范来源；本会话直连官方/公告页仍为客户端渲染
  或 403（同角色池注记），无法逐字抓取正文。上表数值经多个独立公开祈愿计算器与攻略源
  交叉核对一致（基础 0.7%、综合 1.85%、80 硬、软 62–63、75% UP、定轨 2 点最坏 160）：
  - 祈愿模拟/概率计算器：genshin-wishes.com（武器池分页，官方数值口径）
  - 攻略站（fandom/官方公告转引）：官方规则「定轨值上限为 2」「80 抽内必出」
  - 社区软保底统计（pity 分布众数 63 附近，与本仓 weapon_event 实测软 63 一致）
  本仓武器聚合实测（§1b：软 63 / 硬 80 / 75 抽后 0 计数）与上述官方口径一致，故武器池
  按「0.7% / 1.85% / 80 硬 / 63 软 / +6.9%」校准，定轨按「75% UP + 2 点定轨」建模。
