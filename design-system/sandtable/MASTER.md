# Sandtable V2 · 工作台设计系统

2026-10-20 全面重设计。产品为桌面数值实验分析工具，采用项目资源、文档工作区、选择检查器与持续任务队列。详细任务、数据契约和验收见 `docs/专业工作台界面设计.md`。

## 页面结构

功能轨 → 项目浏览器 → 文档标签 → 数据画布 / 选择检查器 → 任务抽屉。默认页是参数扫描分析；另有参数编辑、实验设计、任务、数据交换。图表与数据表占据主要空间。

| 选中表格行 | `#eaf5f5` |

系统中文字体 + Segoe UI / Inter fallback，无外部字体请求。正文 13px；表格 12px；辅助 10–11px；路径 / ID / 数字采用系统等宽字体。4px 基础间距，面板内边距 12–21px，桌面按钮最小 32px 高。标题 19px，避免占据数据空间。

## 组件与行为

- 标题栏、文档标签、局部工具栏、观测图、候选表、检查器、参数表、实验表单、任务抽屉、原生对话框。
- 按钮圆角 3–4px，面板靠分隔线组织；阴影只用于浮层。
- CI、阈值、基线和样例来源均可见；不同单位采用分图。
- 表格右对齐数值，保持稳定行高；修改单元格底色与文字状态同时标记。
- 可见键盘焦点、原生语义控件、命令搜索、复制候选、批量修改、撤销、下载。
- 样例结果绑定其自身快照；草稿修改不覆盖结果来源。
- 响应式局部滚动，不将整张桌面图缩成无法阅读的手机缩略图。

## 技能来源与取舍

UI/UX Pro Max 的通用 design-system 检索未命中专业桌面分析布局，不采用其营销页面推荐。重试产品域命中 Analytics Dashboard，采用 comparative / drill-down / data-dense 思路；UX 域采用宽表局部滚动和批量编辑。信息架构、统计语义和 token 为 Sandtable V2 的具体设计决策。
