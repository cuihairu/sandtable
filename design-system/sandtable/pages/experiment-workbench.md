# Sandtable V2 · 页面约束

继承 `../MASTER.md`，完整设计见 `docs/专业工作台界面设计.md`。

- 默认分析页：一个主指标响应图、两个辅助指标小图、候选表、选择检查器；共享候选选择。图中只有离散观测点和 CI，无未声明的插值。
- 参数页：真实 registry 路径、类型、默认值；友好名按 desc 简化；无统一单位 / 建议区间时显示未定义。搜索、分组、多选倍率、撤销与浏览器保存实际工作。
- 实验页：方法、因子域、场景、指标四段；右侧实时预算、校验和排队。切换方法保留输入，错误就地显示。
- 任务页：当前会话演示任务可取消；结束不生成假结果。抽屉切页持续运行。
- 数据页：CSV / JSON / SVG 实际下载；商业软件通过文件交换，不显示假的调用成功。
- 所有工作区明确样例 / 草稿来源。无伪造哈希、时间或运行历史。
- 页面文案使用实际 KPI 口径：win_rate 全程胜率、retention_d7 D7 留存、gold_per_player 全程人均金币产出。
