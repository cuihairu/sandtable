基准数据（溯源见 `data/public/genshin/sources.md`）：

- **官方公示**（Genshin Impact 5★ 祈愿规则）：基础概率 0.600%、综合概率（含保底）1.600%、
  90 抽内必出、软保底自 74 抽起每抽约 +6%。
- **社区全量样本**（`MsExcel85/genshin-drop-rate`，HoYolab 2025-06-10 发表）：74 个
  character_event banner、22,047,495 次 5★，逐抽计数（本仓聚合
  `data/public/genshin/character-event-pity.json`）。

## 模型偏差发现与修复

**偏差**：旧实现 `hit_rate` 的软保底增量用 `max(0, k − pity_soft_start)·step`（k = 距上次命中
未中抽数）。因抽 n 的 k = n − 1，该式使**软保底实际起于 `pity_soft_start + 2` 抽**——即用户按官方
「自 74 抽起软保底」设置 `pity_soft_start = 74` 时，模型在 76 抽才起跳，爬坡曲线整体右移 2 抽，
且综合概率随之偏离（见下表「修复前」行）。

**修复**：增量改为 `max(0, n − pity_soft_start + 1)·step`（n = 抽数，1 起始），使
`pity_soft_start` 与官方/游戏约定一致（第 1 个获得加成的抽数）。字段文档与单测同步更新。
（`crates/sandtable-core/src/systems/gacha.rs`，commit 见下。）

## 仿真 vs 公开数据对照表

精确分布（逐抽条件率经 `hit_rate` 生存函数）解析计算；MC 仿真（`pull_until_hit` 真 RNG 路径，
2 万 actor）均值与解析一致。

## 注记

1. **社区基础段偏高**：社区样本抽 1–73 经验率均值 ≈0.708%，高于官方 0.6%。这是玩家提交
   愿望数据的已知选择/保证机制混杂偏差，非模型问题；其直接后果是社区期望抽数（60.10）低于
   官方 1/0.016=62.5 与模型（62.30）。模型校准以**官方公示率 + 软保底曲线形态**为准，社区
   均值仅作参考。
2. **社区高抽段伪影**：抽 84–89 社区经验率非单调回落（84:65.3% → 87:61.3% → 88:49.1%），
   对真实单调软保底曲线不可能，判为玩家提交数据在 90 抽硬保底附近的截断/选择伪影。校准测试
   以 `rate[87] < rate[84]` 为金丝雀锁该伪影，可信段取 74–83（模型与社区每抽差 ≤ 0.7pp）。
3. **未采集的公开数据**（如实标注，不脑补，见 sources.md §3）：星穹铁道、Steam 开箱、
   Diablo Immortal、Zendle 等学术基准本会话未能抓到可读来源，不作校准基准。
