# 公开基准校准：gacha-pity 模型 vs 公开数据

日期：2026-10-31。用途：todo「真实案例二期 + 模型校准」的公开数据面解锁（用户令 2026-10-31
「网上收集公开数据做测试」，口径修正：公开数据 = 测试/校准基准，真实运营数据留待用户业务校准）。

基准数据（溯源见 `data/public/genshin/sources.md`）：

- **官方公示**（Genshin Impact 5★ 祈愿规则）：基础概率 0.600%、综合概率（含保底）1.600%、
  90 抽内必出、软保底自 74 抽起每抽约 +6%。
- **社区全量样本**（`MsExcel85/genshin-drop-rate`，HoYolab 2025-06-10 发表）：74 个
  character_event banner、22,047,495 次 5★，逐抽计数（本仓聚合
  `data/public/genshin/character-event-pity.json`）。

## 模型偏差发现与修复

**偏差**：旧实现 `hit_rate` 的软保底增量用 `max(0, k − pity_soft_start)·step`（k = 距上次命中
未中抽数）。因抽 n 的 k = n − 1，该式使**软保底实际起于 `pity_soft_start + 2` 抽**——即用户按官方
「自 74 抽起软保底」设置 `pity_soft_start = 74` 时，模型在 76 抽才起跳，爬坡曲线整体右移 2 抽，
且综合概率随之偏离（见下表「修复前」行）。

**修复**：增量改为 `max(0, n − pity_soft_start + 1)·step`（n = 抽数，1 起始），使
`pity_soft_start` 与官方/游戏约定一致（第 1 个获得加成的抽数）。字段文档与单测同步更新。
（`crates/sandtable-core/src/systems/gacha.rs`，commit 见下。）

## 仿真 vs 公开数据对照表

模型按官方参数 `base_rate=0.006, pity_hard=90, pity_soft_start=74, pity_soft_step=0.06`，
精确分布（逐抽条件率经 `hit_rate` 生存函数）解析计算；MC 仿真（`pull_until_hit` 真 RNG 路径，
2 万 actor）均值与解析一致。

| 指标 | 官方公示 | 模型（修复后） | 社区样本 | 结论 |
|---|---|---|---|---|
| 基础概率 | 0.600% | 0.600%（抽 1–73 恒定） | ≈0.708%（抽 1–73 均值）| 模型与官方一致；社区偏高系玩家提交数据早期命中过报（见注 1）|
| 综合概率 | 1.600% | **1.605%**（差 0.005pp < 0.1pp）| 1.664% | 模型 vs 官方在容差内 ✓ |
| 期望抽数 E[T] | 62.5（=1/0.016）| 62.30 | 60.10 | 模型 vs 官方差 0.20 抽；社区偏低同注 1 |
| 硬保底 | 第 90 抽必中 | 第 90 抽 = 100% | 抽 90 经验率 100% | ✓ |
| 软保底起点 | 第 74 抽起 | 第 74 抽 = 6.6% | 抽 74 = 6.7% | 修复后与社区一致（旧实现 76 抽起，右移 2 抽）|
| 软保底步长 | 约 +6%/抽 | +6%/抽（74–83 每抽差 ≤ 0.7pp vs 社区）| 抽 74→83 约 +6%/抽 | ✓ |
| 软保底高抽段（84–89）| 单调升至约 97% | 单调 66.6%→96.6% | 非单调回落（69→61→49→52%）| 社区高抽段为数据伪影（见注 2），不作模型差依据 |

## 注记

1. **社区基础段偏高**：社区样本抽 1–73 经验率均值 ≈0.708%，高于官方 0.6%。这是玩家提交
   愿望数据的已知选择/保证机制混杂偏差，非模型问题；其直接后果是社区期望抽数（60.10）低于
   官方 1/0.016=62.5 与模型（62.30）。模型校准以**官方公示率 + 软保底曲线形态**为准，社区
   均值仅作参考。
2. **社区高抽段伪影**：抽 84–89 社区经验率非单调回落（84:65.3% → 87:61.3% → 88:49.1%），
   对真实单调软保底曲线不可能，判为玩家提交数据在 90 抽硬保底附近的截断/选择伪影。校准测试
   以 `rate[87] < rate[84]` 为金丝雀锁该伪影，可信段取 74–83（模型与社区每抽差 ≤ 0.7pp）。
3. **未采集的公开数据**（如实标注，不脑补，见 sources.md §3）：星穹铁道、Steam 开箱、
   Diablo Immortal、Zendle 等学术基准本会话未能抓到可读来源，不作校准基准。

## 结论

- sandtable gacha-pity 模型按官方 Genshin 参数可复现官方公示（基础 0.6%、综合 1.6% 差 <0.1pp、
  90 硬保底、74 起软保底 +6%/抽）与社区样本的软保底曲线形态（74–83 差 ≤0.7pp）。
- 修复模型软保底起点 +2 抽偏移（一问题一 commit）。
- 校准用例 = `cargo test -p sandtable-core --test public_calibration`（3 测：官方率/社区曲线/MC 复核对解析）。
- 本项 BLOCKED 解除：公开基准校准完成；真实运营数据校准 = 待用户数据。

## 类别 1：武器池（祈愿）

**数据**（`data/public/genshin/weapon_event-pity.json`，2026-11-01 增补）：75 个 banner、
6,252,311 次 5★、均值 49.8111、综合 2.008%（社区口径）。软保底 63 起、硬边界 80
（81–90 抽位计数为 0，与官方 80 硬保底一致）。63–71 段经验斜率约 +6.9%/抽
（可信单调段）；72 起经验率非单调（72:67.07%→73:68.33%→74:55.47%→75:34.60%），判数据伪影。

**官方口径**（多源交叉核对，sources.md §2）：基础 0.7%、综合 1.85%、80 抽内必出、
软保底约 63 起；无 50/50（双 UP 各 37.5%，首次 UP 75%）；定轨 v5.0 起 **1 点必保**（此前 2 点）。

**校准结论**：模型 `base=0.007, hard=80, soft=63, step=0.043` → 综合 **1.850%**
（差 <0.1pp vs 官方 1.85%，均值 54.054 vs 1/0.0185=54.05）。**步长取 0.043 而非经验斜率
+6.9%**：+6.9% 线性外推在约 77 抽即饱和（0.7%+15×6.9%≥100%），与官方 80 硬保底及数据
78–80 抽有样本矛盾；+6.9% 系社区过报抬高（同角色池基础率过报成因，注 1）。0.043 为
「0.7%/63 软/80 硬」结构下令综合 = 1.85% 的反解（0.04304），且抽 79 率面 73.8% < 100%，
不提前饱和，80 硬保底钳制生效。

**定轨层**（模型扩展 `featured_rate`/`featured_guarantee`，见 gacha.rs `pull_until_featured`）：
`featured_rate=0.375`（所定单武器 37.5%）、`featured_guarantee=1`（1 点必保）。
E[#5★] = 0.375×1 + 0.625×2 = **1.625**；E[pulls] ≈ 1.625 × 54.05 ≈ **87.8**；
最坏 **160 抽**（2×80，与官方口径一致）。仿真（4 万 actor）均值 1.625 与 87.8 复核对解析。
定轨层用独立 RNG 流（`Purpose::GachaFeatured`），不改 5★ 率面（CRN 不挪键）。

## 类别 2：常驻池（标准祈愿）

**数据**（`standard-pity.json`）：dataset 仅 1 条记录（banner_id 200001，全时期合并）、
5,719,299 次 5★、均值 49.1651、综合 2.034%（社区口径）。软保底 74 起、硬边界 90。

**预设修正（诚实）**：任务预设「常驻无软保底」。**数据反驳**——standard 记录 74 抽起
经验率明确爬坡（73:1.55%→74:7.46%→75:13.28%…，74 起 >3× 基础段），且官方公示常驻与
角色同构（0.6%/1.6%/74 软/90 硬）。**常驻池有软保底，与角色池同构**，本仓按同构校准。
注意 standard 记录绝对水平过报最重（综合 2.034% vs 官方 1.6%；抽 1 经验率 1.156% ≈
基础率 1.9 倍），故仅取**结构**（软 74/硬 90），绝对率以官方为准。

**校准结论**：模型 `0.006/90/74/0.06`（=角色池）→ 综合 **1.605%** vs 官方 1.6%（差 0.005pp），
均值 62.30 vs 62.5。**平坦率模型（无软保底）综合仅 1.435%**，不支持官方 1.6%——
再次证明软保底不可缺（同角色池注记）。

## 类别 3：跨游戏（HSR 角色活动跃迁）

**数据**：HSR 官方 hoyolab/wiki 页仍客户端渲染/403，**社区分布数据集未采集**（如实标注）。
但多独立公开祈愿计算器与攻略源交叉核对官方参数一致：基础 0.6%、综合 1.6%、90 硬、
软 74、50/50（光锥池 80 硬/软约 66/75-25）。

**校准结论**：HSR 角色活动跃迁率面与 Genshin 角色池**同构**（0.6%/1.6%/90/74/50-50）；
模型按同参数复现官方 1.6%（差 0.005pp）——验证模型跨游戏泛化（结构同构性，
非 HSR 专属分布数据，不代用 Genshin 数值）。
