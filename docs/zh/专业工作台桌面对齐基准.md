# 专业工作台 · 桌面对齐基准

> 状态：已确立(2026-10-20,截图单)。本页是 WB 批次中桌面(Tauri)侧工作区实现的设计依据。

## 声明

**桌面(Tauri)端工作区实现以 `apps/web` 的 V2 工作台为设计基准**：框架结构、组件划分、视觉 tokens 与交互语义对齐 `apps/web/public/prototype/`,不另起一套桌面专属设计。桌面壳按既有架构复用同一 React UI(见 docs 18 章:`frontendDist` 内联、`lib/wasm.ts` 桌面分支),因此"对齐 V2"在多数界面上是自动成立的;需要显式对齐的是工作区壳之外的原生部分(文件对话框、窗口、原生菜单)不引入偏离 V2 的样式。

WB 后续批次(WB-02 起)执行时依此基准;与 V2 冲突时先改本基准或 V2 设计稿,不悄悄分叉。

## 桌面差异的登记位置

桌面与浏览器的执行差异(进度 Channel、replicate 边界取消、无 WASM 预算门、原生文件对话框)已在 `docs/专业工作台V2能力盘点.md` §5/§6 登记;这些差异属于执行层,不构成偏离 V2 视觉与交互的理由。
