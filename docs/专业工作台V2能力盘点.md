## 4. `sweep_plan` 三条采样路径复用结论(WB-01.04)

**结论:Grid / Random / `latin_hypercube` 三条路径全部已实现、已测试、双端透传,正式 UI 只需把表单编译成实验 YAML 后调 `planSweep`,不得重写采样器。**

| 路径 | 内核实现 | 语义 | 复用证据 |
|---|---|---|---|
| Grid | `sweep.rs:226-258` | 逐维格点笛卡尔积;先算账再物化,超 `MAX_CANDIDATES=10_000`(`sweep.rs:24`)提前拒绝 | wasm 测试 3 候选/双轴 3×3(`wasm/lib.rs:303-322,375-411`);桌面同构(`desktop/lib.rs:560-563`) |
